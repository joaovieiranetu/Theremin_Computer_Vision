# Theremin_Computer_Vision
O Theremin é um instrumento tocado sem contacto físico. Este projeto em Python recria essa dinâmica por visão computacional com OpenCV: a webcam rastreia uma caneta de qualquer cor por segmentação no espaço HSV. O sistema mapeia o eixo X para selecionar a nota musical e o eixo Y para ajustar o volume em tempo real via sounddevice.
